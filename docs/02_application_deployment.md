# Module 02: Application Deployment

## Objective

Deploy a complete web application infrastructure.

## Architecture

    Nginx
     |
    Docker Container
     |
    FastAPI Application
     |
    PostgreSQL Database

## Tasks

### Python Application

Build:

-   REST API
-   configuration management
-   database connection

### Docker

Learn:

-   Dockerfile
-   image building
-   containers
-   volumes
-   networks

### Nginx

Configure:

-   reverse proxy
-   upstream server
-   static files
-   logs

## Troubleshooting

Practice fixing:

-   502 Bad Gateway
-   container crash
-   database connection failure
-   wrong configuration
