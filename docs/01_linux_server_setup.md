# Module 01: Linux Server Setup

## Objective

Create and manage Linux servers like a real system administrator.

## Environment

-   Ubuntu Server 24.04 LTS
-   Virtual machines
-   SSH remote management

## Tasks

### Server Initialization

-   Install required packages
-   Configure hostname
-   Configure timezone
-   Update packages

### User Management

Practice:

-   creating users
-   groups
-   sudo permissions
-   file ownership

### Service Management

Learn:

-   systemd
-   service status
-   logs
-   process management

Commands:

-   systemctl
-   journalctl
-   ps
-   top
-   htop

## Troubleshooting Practice

Examples:

-   service cannot start
-   port unavailable
-   permission denied
-   disk full
