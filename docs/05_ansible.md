# Module 05: Ansible Infrastructure Automation

## Objective

Automatically configure servers.

## Manual Method

Before:

    Server 1
    install nginx

    Server 2
    install nginx

    Server 3
    install nginx

## Ansible Method

After:

    Playbook

       |

    Multiple Servers

## Tasks

Create playbooks for:

-   user creation
-   package installation
-   nginx deployment
-   docker installation
-   server initialization

## Goal

Learn Infrastructure as Code thinking: repeatable, predictable,
automated infrastructure.
